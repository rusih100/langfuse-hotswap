# Шаблоны

Сообщения формируются по правилам подстановки Langfuse, поэтому результат совпадает с тем, что
показывает playground. Механизм подстановки — копия `TemplateParser` из SDK; контрактный тест
проверяет, что оба выдают одинаковый текст.

- Переменная — это всё, что находится между `{{` и ближайшим `}}`, без пробелов по краям.
  Значения подставляются через `str()` без экранирования; `None` превращается в пустую строку.
- Все переменные обязательны. В отличие от `prompt.compile()`, отсутствующая переменная — это
  ошибка, а не оставленный как есть текст. Проверку выполняет шаблон LangChain, поэтому
  выбрасывается `KeyError` с именами недостающих переменных.
- Одиночные фигурные скобки и HTML остаются без изменений. Секции Mustache не поддерживаются:
  `{{#flag}}` — это переменная с именем `#flag`.
- Плейсхолдеры заполняются из входной переменной с тем же именем; она должна содержать список
  сообщений. Переменные внутри этих сообщений не подставляются.
- Текстовый промпт превращается в одно сообщение с ролью `human`. Роли, неизвестные LangChain,
  например `developer`, сохраняются как `ChatMessage` с соответствующей ролью.
- Переменные с именами `stop` и `self` отклоняются LangChain.
