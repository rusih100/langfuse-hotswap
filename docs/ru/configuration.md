# Конфигурация

## Источники параметров

| Источник | Что в нём задаётся | Примеры |
|---|---|---|
| Конфигурация промпта в Langfuse | Всё, что подбирается вместе с промптом | `model`, `model_provider`, `temperature`, `max_tokens`, `reasoning_effort` |
| Аргументы фабрики | Инфраструктура и всё, что не выражается в JSON | HTTP-клиенты, ограничители частоты запросов, ключи, адреса, тайм-ауты, повторные попытки |

Объединённые параметры передаются в `init_chat_model`. Приоритет по возрастанию: конфигурация
промпта, аргументы фабрики, аргументы провайдера. Код всегда имеет последнее слово, поэтому правка
промпта не может изменить то, что задано в коде.

```python
factory = LangfuseChainFactory(
    langfuse,
    # Передаются каждому провайдеру и имеют приоритет над конфигурацией промпта.
    timeout=30,
    max_retries=2,
    # Передаются только тому провайдеру, которого выбрала конфигурация промпта.
    providers={
        "openai": {"base_url": "http://localhost:11434/v1", "api_key": "ollama"},
        "google_genai": {"vertexai": True, "project": "my-gcp-project"},
    },
)
```

- Аргументы фабрики передаются каждому провайдеру. Если конструктор провайдера не принимает один
  из них, цепочка не соберётся, поэтому ключи, адреса и другие специфичные для провайдера
  аргументы следует указывать в `providers`.
- Конфигурация обязана указать провайдера в `model_provider`. По имени модели он не определяется:
  конфигурация `{"model": "claude-sonnet-5-5"}` без провайдера приводит к `ChainBuildError`.
  Благодаря этому переименование модели не может незаметно перенаправить запросы — вместе с
  ключами — к другому провайдеру. Синтаксис `provider:model` из `init_chat_model` не
  поддерживается: имя модели передаётся как есть, так что `ft:gpt-4o-mini:org::id` — это имя
  модели. Имена провайдеров нормализуются так же, как в `init_chat_model`: `google-genai` и
  `google_genai` равнозначны.
- Без `providers` конфигурация может выбрать любого провайдера, пакет которого установлен; он
  получит аргументы фабрики и ключи из переменных окружения. Чтобы ограничить выбор провайдерами,
  настроенными в коде, задайте `providers`; чтобы закрепить одного провайдера для всех промптов,
  передайте `model_provider` в аргументах фабрики.
- При заданном `providers` конфигурация может выбрать только одного из перечисленных провайдеров.
- Если в объединённых параметрах нет `model`, цепочка выбрасывает `ChainBuildError`.

## Выбор версии промпта

Метод `create` принимает `label` или `version`, а также параметры `get_prompt`:
`cache_ttl_seconds`, `fallback`, `max_retries` и `fetch_timeout_seconds`.

```python
chain = factory.create("support-reply", label="staging", cache_ttl_seconds=30)
pinned = factory.create("support-reply", version=12)
```

`fallback` используется, когда промпт получить не удалось, а кеш SDK пуст. Его конфигурация
пуста, поэтому для его работы в аргументах фабрики должны быть заданы `model` и `model_provider`.
SDK не объединяет параллельные запросы при пустом кеше, поэтому, если при запуске ожидается
большой поток вызовов, прогрейте цепочку заранее — например, вызовом
`chain.get_input_schema()`, который получает промпт и собирает цепочку.
